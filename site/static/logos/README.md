# Logos on the wall

Vector masters fetched from Wikimedia Commons for the "built by people who have stood up operations for" wall (src/lib/content/home.js). Each is a trademark of its owner, used nominatively to name a prior employer of the founding team. None is an endorsement, and the wall says so.

U.S. Cyber Command and Naval Special Warfare are rendered as set text on purpose: their seals are official insignia whose commercial use is restricted, so they stay off the page.

Rendering: the wall greys the marks and, on the dark theme, inverts them so a black wordmark reads white. Hover restores full opacity but not colour.

To add a mark: drop an SVG here, add `{ name, file }` to `logoWall.items`, and note its source in this table.
