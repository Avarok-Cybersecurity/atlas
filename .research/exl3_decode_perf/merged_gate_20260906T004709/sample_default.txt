The user wants a Python function that merges two sorted lists into one sorted list, followed by a two-sentence complexity explanation. This is the classic merge step from merge sort. I'll write a clean implementation using the two-pointer technique, then explain time and space complexity concisely.

----
```python
def merge_sorted_lists(list1, list2):
    merged = []
    i, j = 0, 0

    while i < len(list1) and j < len(list2):
        if list1[i] <= list2[j]:
            merged.append(list1[i])
            i += 1
        else:
            merged.append(list2[j])
            j += 1

    merged.extend(list1[i:])
    merged.extend(list2[j:])

    return merged
```

**Complexity:** The algorithm runs in O(n + m) time, where n and m are the lengths of the two input lists,
