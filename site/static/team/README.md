# Portraits

The five portraits on the company page (`team.people` in `src/lib/content/company.js`).

Supplied by the company, from its own team slide of September 2026, as 400 px squares,
scaled to 320 px and saved as WebP. They are pictures of real people. Each person confirms
their own photo, title, line and profile link, and an entry changes only on that person's
word.

To replace one: a square image of at least 320 px, saved as `<first>-<last>.webp` under this
folder, then `bun run guide` so the ledger records the new file.
